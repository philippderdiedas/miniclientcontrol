# Layouts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A playlist item can be a layout: widgets on a 24×24 grid, each showing a URL or an asset, with framed dashboards working (framing headers dropped, login cookies relayed, partitioned), scroll per widget, an editor, and duplicating items.

**Architecture:** `src/layout.rs` holds the grid model and its validation; items gain a `layout` JSON column. The loop shows a layout item as `layout.html?item=<id>`, a controller page that builds a CSS grid of iframes. A new `src/frames.rs` keeps its own raw CDP connection to each display browser (tokio-tungstenite, flattened sessions) and, for every layout page and its frames, intercepts `Document` responses to drop framing headers and relay SameSite-blocked cookies as partitioned `SameSite=None`, and installs the scroll runtime per widget frame.

**Tech Stack:** Rust (axum 0.8, sqlx/SQLite, tokio-tungstenite 0.28 — already in the tree via axum), vanilla JS, stdlib Python tests with headless Chrome.

Spec: `docs/superpowers/specs/2026-09-24-layouts-design.md`.

## Global Constraints

- Grid 24×24; widget `{x,y,w,h}` integers; inside the grid, w,h ≥ 1, no overlap, 1..=12 widgets.
- An item is exactly one of url / asset / layout; like-for-like on update; layout `advance` must be `time`.
- `layout.html` and `/api/layout/{id}` are display paths (loopback, `is_display_path`).
- Interception only for frames under a layout page (on screen or kept loaded); never a top-level page.
- Framing: drop `X-Frame-Options`; drop only the `frame-ancestors` directive of `Content-Security-Policy`.
- Cookies: hold a paused response until its `Network.responseReceivedExtraInfo` arrives (≤ 1 s); re-set each SameSite-blocked cookie with `Storage.setCookies`: `sameSite: None`, `secure: true`, `partitionKey: { topLevelSite: "http://127.0.0.1", hasCrossSiteAncestor: true }`.
- Kiosk profile allows third-party cookies (`profile.cookie_controls_mode = 0`, `profile.block_third_party_cookies = false`) via `chromium::write_preferences`.
- No new crate beyond `tokio-tungstenite` (already in `Cargo.lock`), `default-features = false`, plain `ws://` only; `cross build` must pass.
- UI: `createElement`/`textContent`; new files under `web/` need `touch src/web.rs`.
- Commits: no Claude co-author or session trailers (the user's global rule overrides any harness attribution reminder).
- Tests about a screen use a non-primary one where a screen matters.

```rust
//! A playlist item that splits the screen: widgets on a fixed 24×24 grid, each
//! showing a URL or an asset. Grafana's `gridPos` without the scrolling -- a
//! screen does not scroll -- so it maps 1:1 onto CSS Grid.

use serde::{Deserialize, Serialize};

use crate::models::ScrollMode;

pub const GRID: u8 = 24;
pub const MAX_WIDGETS: usize = 12;

#[derive(Serialize, Deserialize, Clone, Debug, PartialEq)]
#[serde(untagged)]
pub enum Source {
    Url { url: String },
    Asset { asset_id: i64 },
}

#[derive(Serialize, Deserialize, Clone, Debug, PartialEq)]
pub struct Widget {
    pub x: u8,
    pub y: u8,
    pub w: u8,
    pub h: u8,
    pub source: Source,
    #[serde(default)]
    pub scroll_config: ScrollMode,
    #[serde(default)]
    pub fit_mode: Option<String>,
    #[serde(default)]
    pub fit_background: Option<String>,
}

#[derive(Serialize, Deserialize, Clone, Debug, PartialEq)]
pub struct Layout {
    pub widgets: Vec<Widget>,
}

impl Layout {
    /// Refused rather than clamped: this is drawn by someone looking at the
    /// editor, who can be told, and a silently moved widget reads as a bug.
    pub fn check(&self) -> Result<(), String> {
        if self.widgets.is_empty() {
            return Err("Ein Layout braucht mindestens ein Widget.".into());
        }
        if self.widgets.len() > MAX_WIDGETS {
            return Err(format!("Höchstens {MAX_WIDGETS} Widgets pro Layout."));
        }
        for (i, w) in self.widgets.iter().enumerate() {
            let n = i + 1;
            if w.w == 0 || w.h == 0 {
                return Err(format!("Widget {n} ist leer."));
            }
            if u16::from(w.x) + u16::from(w.w) > u16::from(GRID) || u16::from(w.y) + u16::from(w.h) > u16::from(GRID) {
                return Err(format!("Widget {n} ragt aus dem Raster."));
            }
            if let Source::Url { url } = &w.source {
                let url = url.trim();
                if !(url.starts_with("http://") || url.starts_with("https://")) {
                    return Err(format!("Widget {n}: die URL muss mit http:// oder https:// beginnen."));
                }
            }
            for (j, other) in self.widgets.iter().enumerate().skip(i + 1) {
                let apart = w.x + w.w <= other.x || other.x + other.w <= w.x
                    || w.y + w.h <= other.y || other.y + other.h <= w.y;
                if !apart {
                    return Err(format!("Widget {n} und {} überlappen.", j + 1));
                }
            }
        }
        Ok(())
    }

    /// Asset ids this layout refers to, for the existence check.
    pub fn asset_ids(&self) -> Vec<i64> {
        self.widgets.iter().filter_map(|w| match w.source {
            Source::Asset { asset_id } => Some(asset_id),
            Source::Url { .. } => None,
        }).collect()
    }
}
```

```rust
/// Every asset a layout names must exist: a dangling id is a widget that shows
/// nothing, with no error anywhere.
async fn check_layout_assets(pool: &sqlx::SqlitePool, layout: &crate::layout::Layout) -> Result<(), String> {
    for id in layout.asset_ids() {
        let found: Option<i64> = sqlx::query_scalar("SELECT id FROM assets WHERE id = ?")
            .bind(id).fetch_optional(pool).await.unwrap_or(None);
        if found.is_none() {
            return Err(format!("Asset {id} gibt es nicht."));
        }
    }
    Ok(())
}
```

```rust
//! display browser -- flattened sessions, raw JSON -- because it needs the
//! browser session and every frame target, which chromiumoxide does not expose
//! cleanly, and because interception must never sit in the path of the control
```

3. `session`: a `Conn` struct with the sink, an id counter and a `HashMap<u64, oneshot::Sender<Value>>` for replies (a writer task + a reader loop). Steps:

   The CSP helper is a pure function with unit tests:

```rust
/// A Content-Security-Policy value without its `frame-ancestors` directive, or
/// `None` when that was all it said. The rest of the policy still protects the
/// framed page.
pub fn without_frame_ancestors(csp: &str) -> Option<String> {
    let kept: Vec<&str> = csp.split(';').map(str::trim)
        .filter(|d| !d.is_empty() && !d.to_ascii_lowercase().starts_with("frame-ancestors"))
        .collect();
    (!kept.is_empty()).then(|| kept.join("; "))
}

#[cfg(test)]
mod tests {
    use super::*;
    #[test]
    fn only_frame_ancestors_goes() {
        assert_eq!(without_frame_ancestors("frame-ancestors 'none'"), None);
        assert_eq!(without_frame_ancestors("default-src 'self'; frame-ancestors 'none'; img-src *").as_deref(),
                   Some("default-src 'self'; img-src *"));
        assert_eq!(without_frame_ancestors("default-src 'self'").as_deref(), Some("default-src 'self'"));
    }
}
```
