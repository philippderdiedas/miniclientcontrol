Ein Token ist ein Zugang für Skripte und KI-Assistenten (MCP). Er handelt als dieses Konto, mit der Rolle, die es gerade hat: Mit dem Token eines Redakteurs werden Änderungen zu Vorschlägen, die ein Manager freigibt. Für einen KI-Assistenten ist deshalb ein eigenes Konto mit passender Rolle meist die beste Wahl. Ein Token kann weder das Passwort noch andere Tokens ändern.
